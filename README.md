# PolicyCore Hackathon Starter

PolicyCore is a Socotra-inspired policy administration MVP for Texas homeowners insurance built with Next.js, TypeScript, Supabase, and Vercel.

## Quick Start

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Included in v0.1
- AI instruction repository (`AGENTS.md` + scoped instructions).
- Product, architecture, database, API, AI, and demo docs under `docs/`.
- Next.js App Router scaffold with `/api/v1` endpoints.
- Shared Zod contracts under `src/lib/contracts`.
- Domain logic for deterministic rating + AI wrappers.
- Supabase migration and seed templates under `supabase/`.
