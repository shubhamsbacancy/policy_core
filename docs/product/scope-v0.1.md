# Scope v0.1 (Specification)

## Objective
Define implementation-ready blueprint artifacts before feature development.

## Deliverables
- AI instruction repository (`AGENTS.md` + scoped instructions).
- Codex command/risk policy (`codex/rules/project.rules`).
- Product scope docs for v0.1 and v1 hackathon.
- System architecture baseline.
- Initial Supabase schema and RLS policy model.
- Shared API contracts and endpoint map.
- Demo narrative draft and acceptance checks.

## Acceptance Criteria
- Required entities and endpoint groups are documented and reflected in code stubs.
- API payload shapes are typed with Zod and exported TypeScript types.
- Migration includes required tables and base RLS policies.
- Version and out-of-scope boundaries are explicit.
